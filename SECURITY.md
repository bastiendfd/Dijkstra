# Security Policy

## Supported versions

Security fixes are provided only for the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Instead, contact the repository owner privately through their GitHub profile with:

- a concise description of the issue;
- steps to reproduce it;
- affected files or versions; and
- any suggested mitigation, if available.

The maintainer will acknowledge the report, assess impact, and coordinate disclosure where appropriate.

## Scope

This repository is an educational, local shortest-path example. It does not operate a hosted service, accept credentials, or make claims of production readiness.
